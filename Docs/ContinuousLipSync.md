# 连续口型

Azure 模式使用 Speech SDK 1.51.2 获取同一次合成的 PCM、55 通道动画和 Viseme 时间戳。只驱动其中 28 个嘴部通道；其余面部通道不应用。讯飞、豆包及关闭连续口型的 Azure 仍使用原播放路径与 SALSA。

文字或拼音只描述内容，不包含真实发音时长，不能单独生成精确时间轴。精确链路需要同一次 TTS 返回的 PCM 与逐音素/Viseme 时间戳；其他 TTS 若能提供这些数据，可实现 `IAlignedTTSService` 并发布 `AlignedSpeechSegment`，播放器和模型适配无需改动。没有时间戳时继续使用 SALSA。

## 使用

1. 在运行时「设置 → 机体模块 → 发声」配置 Azure 服务来源、区域及音色。
2. 开启「连续口型（按小句准备）」并保存。默认使用自然克制的强度：嘴部 0.85、下颌 0.7、时间偏移 0。
3. 用「验证口型 · 固定语句」试听。完成提示会显示连续口型、Viseme 或 SALSA，以及降级原因。
4. 分别切换 test / girl 检查正面与侧面的闭唇、圆唇和露齿。两个模型的参数独立保存。

正数时间偏移表示嘴部提前。优先保持零偏移，只有实际音响/显示设备存在额外延迟时再微调。

## 编辑器校准与同音频比较

`Tools → Voice Chat → Mouth Calibration` 可选择角色的 `AlignedMouthDriver`：

- 逐通道预览、恢复中性姿态。
- 获取最近一次试听的小句，或载入本地音频/动画 JSON 样本。
- 拖动音频时间定位姿态；样本保存不含服务配置或密钥。
- 在播放模式以完全相同的 PCM 回放 A（SALSA）与 B（连续口型）。

`Assets/MyCharacter/Config/MouthProfiles/` 保存两个角色的命名映射及覆盖报告。每项支持强度、最大权重、中性值和近似项标识。索引只在运行时解析缓存；不要把一个模型的索引复制给另一个模型。

`Install Continuous Mouth Animation` 会重新生成主场景绑定及映射，因此手工校准过资产后不要无意重复运行。普通播放和打包不运行安装器。

## 时间轴和生命周期

- 完整小句准备后提交；优先句末，40 字后允许软标点切分，80 字或 1.2 秒等待上限触发切分。
- 最多两个未播放完成的小句。播放结束确认释放生产者配额，避免长回答累积无限音频。
- 帧时间由 `FrameIndex / 60` 确定，Viseme 时间由 ticks / 10,000,000 确定。小句基准由此前 PCM 采样总数确定，不再叠加事件到达时间。
- 播放器累计采样数跨越循环 Clip；重新缓冲时冻结音频时间，口型短暂回到中性。恢复时继续同一时间轴。
- 网络事件只产生普通数据；Unity 对象只在主线程更新。每轮采用独立收件队列，取消后迟到的音频、动画和完成事件无法污染新轮次。
- SALSA 在新驱动拥有嘴部期间停用；Emoter 仅屏蔽与映射目标冲突的组件。Animator 和队列更新之后应用嘴部结果；结束、切换或停用时恢复。
- CC 表达式由网格形变和导出文件中的配套骨骼修正共同组成。使用原始 JSON 的下颌、牙齿和舌头修正，转换到 Unity 坐标，统一按同一通道权重应用；不额外叠加猜测的张嘴角度。拥有嘴部期间停用原 BoneDriver 的对应骨骼开关，其他骨骼仍正常驱动。

## 数据兼容与降级

真实 `zh-CN-XiaoxiaoNeural` 返回过小幅负数嘴角系数（例如 -0.046）；解析器对嘴部 -0.1 至 1.1 内的轻微越界限幅至 0–1，其余严重越界或非有限数视为异常。眼部旋转等未使用通道不参与嘴部驱动。

连续帧缺失、相互冲突或格式错误时使用有效 Viseme；没有有效 Viseme 时保留音频并使用 SALSA。只有明确拒绝动画参数且尚未提交音频的小句，才通过 REST 重试音频；不会重复已播放小句，不会自动更换音色。

## 验证入口

- `LipSyncValidation.Run`：安装检查、解析、分句、模型映射、SDK 加载、生产者背压/取消，以及已有 Azure/PCM 离线测试。会安装并保存主场景，请在隔离副本执行。
- `LipSyncValidation.CaptureLive`：从本机配置，或隔离副本 `.work/lipsync/live-settings.json` 读取 Azure 配置，采集固定中文/英文语音。输出样本和原始事件，不输出密钥。
- `LipSyncValidation.ReprocessCapture`：离线重放原始真实事件，验证解析，无新增 API 请求。
- `LipSyncVisualValidation.Render`：两个模型的正面/侧面合成测试姿态及真实样本关键帧，场景不保存。
- `LipSyncPlayModeValidation.Run`：隔离模型运行、句间断粮、32 秒循环播放、切换角色及迟到回调隔离，场景不保存。

测试输出在 `.work/lipsync`，被 Git 忽略。SDK 与 Windows 原生依赖在 `Assets/Plugins/AzureSpeech`，版本和许可随项目保留。
